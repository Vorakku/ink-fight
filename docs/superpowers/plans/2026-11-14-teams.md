# Teams Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Red / Blue / Free-for-all teams, a team-coloured bandanna on every red or blue fighter, and a
frozen setup phase that a Start button ends.

**Architecture:** A `team` typed array in `Sim` replaces `type` in every friend-or-foe check
(free-for-all is `2 + type`, so today's behaviour is the default). The renderer scans each sprite once
for its top edge and ties a band there. `App.tsx` adds a team picker, a `started` flag that holds the
sim still until Start, and red/blue totals in the tally.

**Tech Stack:** React 19 + TypeScript + Vite, canvas 2D, `node checks/sim.check.ts` (plain `assert`).

**Spec:** `docs/superpowers/specs/2026-11-14-teams-design.md`

## Global Constraints

- **Do not run anything without asking the owner**: no `npm run check`, build, lint, type check, dev
  server or browser. Write checks and leave them unrun. **Do not commit** unless the owner asks.
- Typed arrays only, reset in `spawn()`, no allocation in `step()` (style guide, Behaviour rules).
- One optional `UnitDef` field per new per-fighter knob, with a one-line comment.
- Keep fighter indices; never reorder `UNITS`.
- Team values: `RED = 0`, `BLUE = 1`, free-for-all stored as `2 + type`. Colours: red `#e5484d`,
  blue `#3e7bfa`.
- `spawn()` defaults to free-for-all, so every existing check scene keeps its meaning.
- Mark limits with `// shortcut: <the limit>, <when to fix it>`.

## Review Focus

1. A page with free-for-all *and* red/blue fighters: FFA fights both colours, and both colours fight
   FFA (team `2 + t` never equals 0 or 1). Check added in Task 1.
2. Fighters placed during setup or while paused must settle to normal size, not sit 22% big (the
   `hitT` pop only decays in `step()`). Covered by `settle()` in Task 1 and its check.
3. Anything a fighter creates keeps its side: projectiles (and the swap-remove at the end of the
   projectile loop must copy `pTeam`), stink clouds, thrown landings, hatched geese, summoned snakes.
   Hatch check in Task 1.
4. Clear must zero `teamCounts`, and the UI must go back to setup (Start button, not Pause).
5. A fighter hiding in a bush: its bandanna fades with the body (same `a0` alpha), or it gives away
   the ambush.

**Files:**

- Test: `checks/sim.check.ts` (append before the final `console.log`)

**Interfaces:**
- Produces: `export const RED = 0, BLUE = 1, FFA = -1`; `spawn(t: number, x: number, y: number, team = FFA): number`;

- [ ] **Step 1: Write the checks** (append to `checks/sim.check.ts`, import `RED, BLUE` from the sim)

```ts
// Teams: same type on opposite sides fights; different types on one side don't; free-for-all is the default.
{
  const s = scene(), toast = unit('toast')
  const a = s.spawn(toast, 400, 300, RED), b = s.spawn(toast, 440, 300, BLUE)
  for (let t = 0; t < 30; t++) s.step()
  assert.equal(s.target[a], b, 'a red toast fights a blue toast')
  assert.equal(s.teamCounts[RED], 1); assert.equal(s.teamCounts[BLUE], 1)
}
{
  const s = scene(), a = s.spawn(unit('toast'), 400, 300, RED), b = s.spawn(unit('goose'), 440, 300, RED)
  for (let t = 0; t < 60; t++) s.step()
  assert.equal(s.target[a], -1, 'teammates of different types leave each other alone')
  assert.equal(s.hp[b], UNITS[unit('goose')].hp, 'and nobody gets hurt')
}
{
  const s = scene(), a = s.spawn(unit('toast'), 400, 300), b = s.spawn(unit('toast'), 440, 300)
  assert.equal(s.team[a], 2 + unit('toast'), 'spawn defaults to free-for-all')
  for (let t = 0; t < 30; t++) s.step()
  assert.equal(s.target[a], -1, 'two free-for-all toasts are still one team')
  const r = s.spawn(unit('goose'), 420, 330, RED)
  for (let t = 0; t < 30; t++) s.step()
  assert.notEqual(s.target[r], -1, 'a red fighter fights free-for-all fighters')
  assert.equal(s.team[b], 2 + unit('toast'))
}
// Projectiles carry the shooter's side.
{
  const s = scene()
  s.spawn(unit('archerfish'), 100, 300, BLUE)
  const mate = s.spawn(unit('toast'), 500, 300, BLUE)
  for (let t = 0; t < 120; t++) s.step()
  assert.equal(s.hp[mate], UNITS[unit('toast')].hp, 'no spitting at a teammate')
  const foe = s.spawn(unit('toast'), 500, 360, RED)
  for (let t = 0; t < 180; t++) s.step()
  assert.ok(s.hp[foe] < UNITS[unit('toast')].hp || !s.alive[foe], 'spits at the red one')
}
// A hatched goose keeps its egg's side.
{
  const s = scene(), egg = s.spawn(unit('egg'), 400, 300, BLUE)
  s.hp[egg] = 0.01
  s.spawn(unit('toast'), 415, 300, RED)
  for (let t = 0; t < 120 && s.type[egg] === unit('egg'); t++) s.step()
  assert.equal(s.type[egg], unit('goose'), 'the egg hatched into its own slot')
  assert.equal(s.team[egg], BLUE, 'and the goose is still blue')
}
// Frozen pops settle; clear empties the team tally.
{
  const s = scene(), a = s.spawn(unit('toast'), 400, 300, RED)
  for (let t = 0; t < 30; t++) s.settle()
  assert.equal(s.hitT[a], 0, 'a fighter placed during setup settles to normal size')
  assert.equal(s.x[a], s.px[a], 'and settle() moves nobody')
  s.clear()
  assert.equal(s.teamCounts[RED], 0, 'clear empties the team tally')
}
```

### Task 2: Bandanna

**Files:**
- Modify: `src/game/render.ts` (unit draw loop, after the body is drawn and before `c.globalAlpha = 1`)
- Modify: `src/game/units.ts` (`UnitDef`: `band?: number // sprite-px y of the team bandanna, where the top-edge scan guesses wrong`)

**Interfaces:**
- Consumes: `sim.team` from Task 1 (`< 2` means red/blue).
- Produces: `bandOf(img: HTMLCanvasElement): [y: number, x0: number, x1: number]` in `render.ts`, in
  sprite px (0..48), cached in a module-level `Map` keyed by canvas.

- [ ] **Step 1: `bandOf`**: `getImageData` once per canvas (they're 144 px, `SS = 3`). Scan rows top-down
  for the first row with alpha > 128, ignoring rows below sprite y 40 (the ground shadow). The band
  sits 3 sprite px under that top edge; `x0`/`x1` are the opaque span on that row. Cache the result.

- [ ] **Step 2: Draw it** when `sim.team[i] < 2` and the fighter isn't an egg (`stage !== 1`), using
  the sprite that was just drawn (`img`; the snake uses `sprites.snake[0]`). In sprite-local coords
  (feet at 0, so `y - 44`): a 3 px band from `x0 - 0.5` to `x1 + 0.5`, team colour, `INK` outline at
  0.8 px. A knot at the back end (`x0`, since sprites face right) and two tails, about 6 and 5 px long,
  trailing back, each swinging by `Math.sin(sim.tick * 0.3 + i + k) * 1.5`. Alpha `a0`, so a hidden
  fighter's band fades with it. `def.band` overrides `y` when set.
  `// shortcut: one scan per sprite guesses the head from the top edge; set def.band on fighters where it lands on a wing or prop`
